# AI-агент для рутинных задач разработки

Языко-агностичный AI-агент: ускоряет рутинную работу в кодинге (поиск,
чтение, правка файлов по инструкции) в любом проекте — Godot/GDScript,
веб-стек и т.д. Работает на бесплатных лимитах через цепочку провайдеров
Groq → OpenRouter → Gemini.

Пока реализовано (Этап 1–2 из roadmap): ядро агента, цепочка провайдеров,
универсальные инструменты работы с файлами, базовый цикл с ограничением
шагов. Desktop-интерфейс на PySide6 — в планах (Этап 5).

## Установка

```bash
git clone <твой-репозиторий>
cd ai_agent
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Впиши в `.env` хотя бы один API-ключ:
- Groq (бесплатно): https://console.groq.com/keys
- OpenRouter (бесплатно): https://openrouter.ai/keys
- Gemini (бесплатно): https://aistudio.google.com/apikey

## Запуск

**Перед каждой сессией сделай `git commit` в своём проекте** — это единственный механизм отката, если агент внесёт неудачную правку.

```bash
python main.py
```

Далее:
1. Укажи путь к корню проекта, который агент будет анализировать.
2. Перечисли файлы, которые агент может изменять в этой сессии (или оставь пустым — тогда только чтение).
3. Пиши задачи в свободной форме, например: "найди все места, где используется health, и покажи их".
